# Jinbo Wen — Academic Homepage

Personal academic website for [Jinbo Wen](https://jinbowen1019.github.io/), hosted with GitHub Pages.

The homepage is a dependency-free static site. It is organized around biography, news, education, research experience, selected publications, honors, and academic service. Publications are split into:

1. First/co-first-author journal papers.
2. Collaborative journal papers limited to CCF-A venues.

## Local preview

Open `index.html` directly, or serve the repository root with any static HTTP server.
